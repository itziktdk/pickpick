# PickPick 📦

> כל החבילות שלך. במקום אחד.

אפליקציית מעקב חבילות ומשלוחים בעברית — PWA מודרנית עם חוויית משתמש מהשורה הראשונה.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + Framer Motion
- Zustand (state management)
- PWA (service worker, manifest, offline)

## Getting Started
```bash
npm install
npm run dev
```

## Features (MVP)
- 🏠 דשבורד עם כרטיסי חבילות
- 🔍 סינון לפי סטטוס
- 📦 דף פרטי חבילה עם ציר זמן
- ➕ הוספה ידנית של חבילה
- ⚙️ הגדרות (placeholder לאינטגרציות עתידיות)
- 📱 PWA — התקנה על מסך הבית
- 🇮🇱 RTL מלא בעברית
